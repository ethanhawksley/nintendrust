A browser-based NES emulator built with Rust and WebAssembly. Load an NROM .nes file to play.

Controls

The controls on the NES controller have been mapped to various keys.

  • A - Z Key
  • B - X Key
  • Select - Spacebar
  • Start - Enter Key
  • Up - Up Arrow
  • Down - Down Arrow
  • Left - Left Arrow
  • Right - Right Arrow

How to play the example game

Zooming Secretary is a community made game for the NES.

Your role is a secretary, fetching the information that the telephones require. The first level starts off simple, but it quickly ramps up in difficulty as levels introduce obstructions such as your fellow office workers.

Use the arrow keys to collect a topic from the filing cabinets in the level, and then walk to the phone to drop them off!
